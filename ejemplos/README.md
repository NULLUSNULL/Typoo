# Proyecto de ejemplo

`La isla del faro/` es un proyecto de Typoo ya montado para probar la aplicación
(y, si la habilitas, el asistente de IA) sin tener que crear nada.

## Cómo abrirlo

En Typoo: **Archivo → Abrir proyecto…** y selecciona la carpeta
`ejemplos/La isla del faro`.

## Qué incluye

- **Manuscrito**: 2 capítulos con 3 escenas con texto. Los capítulos y escenas
  tienen **Estado** puesto, así verás los puntos de color en el árbol
  (verde = terminada, naranja = en revisión, rojo = borrador, gris = esbozo).
- **Personajes**: *Mara* (con parte de la ficha rellena) e *Iris* (ficha casi
  vacía, ideal para probar «Sugerir ficha»).
- **Ubicaciones**: *El faro* y *El puerto*.
- **Trama**: *El naufragio*, vinculada a las dos primeras escenas.
- Las escenas tienen marcados **Personajes presentes** y **Punto de vista**, que
  es lo que usan la coherencia y el chat para saber dónde aparece cada personaje.

## Qué probar con la IA (una vez habilitada)

- **Reescribir selección**: selecciona un párrafo de «1.1 · La luz al anochecer»
  y prueba *Pulir* o *Mostrar, no contar*.
- **Sinopsis**: abre una escena → *IA → Dossier → Generar sinopsis* (rellena su
  campo Resumen).
- **Ficha asistida**: abre *Iris* → *IA → Dossier → Sugerir ficha*.
- **Coherencia**: abre *Mara* → *IA → Dossier → Revisar coherencia* (contrasta su
  ficha con las escenas donde aparece).
- **Chat**: *IA → Asistente…* y pregunta «¿qué le oculta Iris a Mara?» o
  «resume el capítulo 1».
